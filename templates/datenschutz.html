3. Data Collection and API Usage

Spotify Web API

This application uses interfaces of the Spotify Web API to provide music and track information. When using corresponding features, technical requests may be transmitted to Spotify servers. No personal data is shared with Spotify unless you explicitly log in with your Spotify account.

For more information, please refer to the Spotify Privacy Policy.

Genius API

This application uses data from the Genius API to display song lyrics. When retrieving lyrics, search queries are forwarded to Genius servers.

For more information, please refer to the Genius Privacy Terms.
